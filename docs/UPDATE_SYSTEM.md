# به‌روزرسانی ویرابات از انتشار عمومی

مخزن `silent4time/virabot` عمومی است. ربات و نصب‌کننده بدون توکن به `https://api.github.com` وصل می‌شوند. سرور توزیع جدا لازم نیست.

![مسیر به‌روزرسانی](update-architecture.svg)

## فایل‌های ثابت انتشار

| فایل | نقش |
|---|---|
| `virabot-update.zip` | بستهٔ نصب |
| `virabot-update.zip.sha256` | یک خط SHA-256، خروجی `sha256sum` |

مثال محتوای جمع‌بررسی:

```text
0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef  virabot-update.zip
```

این جمع‌بررسی امضای ناشر نیست. اگر فایل نباشد یا با بایت‌های بسته نخواند، نصب رد می‌شود و نسخهٔ قدیمی‌تر جایگزین نمی‌شود.

ساخت بسته، بدون انتشار:

```bash
bash tools/pack-update-zip.sh
```

خروجی در `dist/` است. هر دو فایل را به یک انتشار پایدار (نه پیش‌نویس و نه آزمایشی) بچسبانید. این مخزن خودش انتشار نمی‌سازد.

## رفتار

- فقط برچسب سه‌بخشی پایدار. پیش‌نویس و `rc` رد می‌شوند.
- شناسهٔ دارایی از پاسخ API ساخته می‌شود. `browser_download_url` استفاده نمی‌شود.
- تغییر مسیر فقط به `release-assets.githubusercontent.com`، `objects.githubusercontent.com` یا `github-releases.githubusercontent.com`. هدر `Authorization` فرستاده نمی‌شود.
- کش موفق ۶ ساعت و کش خطا ۱ ساعت. اگر `X-RateLimit-Remaining` به صفر برسد تا زمان بازنشانی درخواست تازه زده نمی‌شود.
- دکمهٔ مدیر اصلی یک‌بارمصرف است (۱۵ دقیقه). فروشنده رد می‌شود. صف فقط `apply_release` است.
- `sudo virabot update-worker` با کاربر ریشه نصب می‌کند. قبل از کپی، آرشیو کد و در صورت امکان dump پایگاه در `/root/virabot-backups/` است.
- `config.php` و `storage` جایگزین نمی‌شوند. اگر کپی بشکند، فایل‌های کد از `code.tar` برمی‌گردند و فایل‌های تازه‌ای که در فهرست قبل نبودند حذف می‌شوند. پایگاه داده خودکار برنمی‌گردد.
- اگر برگشت تأیید نشود، وضعیت `failed` با `rolled_back: false` می‌ماند و موفقیت ثبت نمی‌شود.

## نصب اولیه

بسته و جمع‌بررسی را کنار هم بگذارید:

```bash
sudo bash install.sh /root/virabot-update.zip
```

اگر بستهٔ محلی نباشد، `install.sh` با پایتون همان انتشار عمومی را بدون توکن می‌گیرد و جمع‌بررسی را مقایسه می‌کند. توکن محیط نادیده گرفته می‌شود.

بعد از نصب، برای به‌روزرسانی‌های بعدی:

```bash
sudo virabot update-worker
```

کرون ریشه را خودتان اضافه کنید:

```cron
* * * * * /usr/local/bin/virabot update-worker >/dev/null 2>&1
```
